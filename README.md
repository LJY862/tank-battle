# 坦克大战 Tank Battle

一款用纯 HTML + Canvas + JavaScript 编写的经典《坦克大战》(Battle City) 网页游戏,单文件、零依赖,双击 `index.html` 即可在浏览器中游玩。

## 玩法

- 控制你的坦克,击毁所有敌方坦克并**保护底部的基地(老鹰)**。
- 基地一旦被击毁,游戏立即结束。
- 每关敌人会不断从顶部三个出生点出现,全部消灭后进入下一关。
- 拥有 3 条生命,生命耗尽则游戏结束。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动 |
| `空格` / `J` | 射击 |
| `Enter` | 开始 / 暂停 |
| `M` | 静音开关 |

手机 / 触屏设备会自动显示虚拟方向键与射击按钮。

## 特性

- 🧱 可破坏的**砖墙**与不可破坏的**钢铁**墙
- 🌊 **河流**(阻挡坦克但子弹可穿过)、🌿 **草丛**(隐藏坦克)
- 👾 四种敌方坦克:普通、快速、重炮、装甲(3 点血)
- ⭐ 道具系统:加速升级、护盾、加命、全屏炸弹
- 🔊 音效(Web Audio API 实时合成,无外部资源)
- 📱 响应式布局,支持触屏操作

## 运行方式

直接用浏览器打开 `index.html` 即可,无需构建、无需服务器、无需任何依赖。

也可以本地起一个静态服务:

```bash
python -m http.server 8080
# 然后访问 http://localhost:8080
```
